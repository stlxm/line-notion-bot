# LINE Notion Bot

LINEを入口に、家計簿・予算・カード利用通知・固定費/サブスク・貸し借り・メモ・特売・URL保存・Notion・Gemini AIをまとめて扱う個人向けBotです。

## ドキュメント

- `SETUP.md`: 初期構築、環境変数、Notion DB、GAS、Render設定
- `MAINTENANCE.md`: 日常保守、障害切り分け、復旧
- `DEVELOPMENT.md`: 長期ロードマップ、進捗、次回再開位置
- `UI_DESIGN.md`: LINE UIとPostback設計ルール
- `PHASE1_TEST.md`: カード自動化テスト
- `PHASE2_TEST.md`: 月次・予算判断テスト
- `PHASE3_TEST.md`: Phase 3A/3B テスト
- `PHASE5_TEST.md`: Phase 4/5 実機テスト
- `FLYER_TEST.md`: サミットチラシ・生活カレンダー実機テスト
- `gas/README.md`: GAS固有設定

機能変更時は README.md / SETUP.md / DEVELOPMENT.md を更新し、UI変更時は UI_DESIGN.md も更新します。

# Phase 4 — メモ・URLを行動に変える

状態: **実装済み・要実機確認**

正式対象:

```text
#50 メモ期限
#53 メモ自動分類
#54 買い物リスト
#56 URL保存時タイトル取得
#57 URLカテゴリ分類
```

使い方:

```text
メモ 住民票を明日までに提出
メモ 9/20までに大学へ連絡
買い物 牛乳
買い物リスト
買った 牛乳
https://example.com/
```

メモは `期限 / 分類 / 完了` を保存します。分類は `買い物 / やること / 予定 / アイデア / その他`。URLはページタイトル・ドメイン・カテゴリ・保存日時を取得し、既存の `後で見るURL` DBへ保存します。Phase 4の分類ではGeminiを使いません。

# Phase 5 — AIの説明責任と改善

状態: **主要機能実装済み・要実機確認**

正式対象:

```text
#61 AI回答 👍 / 👎 評価
#67 AIが参照したDBを表示
#68 AI回答の根拠表示
#72 AI改善内容をDBルーターへ反映
#73 Notion DBヘルスチェック
```

AI質問:

```text
AI 今月の食費を分析して
```

回答末尾に次を自動表示します。

```text
【参照DB】
・家計簿
・月別管理

【根拠】
参照DBから取得した実データ、質問の「今月」に合わせて期間を絞ったデータ
```

評価:

```text
AI評価 👍
AI評価 👎
```

メインメニューにも `👍 直前AI回答を評価 / 👎 直前AI回答を評価` を追加しています。Message actionなので、押した瞬間に選択した評価がトークへ表示されます。現時点ではAI回答そのものの直下ではなく、メインメニューから評価する方式です。

`👎` の後に `AI改善` を使うと、具体的な期待回答を既存のAI改善ログへ保存できます。過去の `👎 / 改善` ログに記録された参照DBは、似た質問で次回のDB選択候補として利用します。

Notion DBヘルスチェック:

```text
DBヘルスチェック
```

主要DBについて、環境変数の有無・Notion APIアクセス・必須プロパティの不足をまとめて確認します。秘密値は表示しません。

AI改善ログDBにはPhase 5用に以下を追加済みです。

```text
評価 Select: 👍 / 👎 / 改善
参照DB Rich text
根拠 Rich text
```
