# LINE Notion Bot

LINEを入口に、家計簿・予算・カード利用通知・固定費/サブスク・貸し借り・メモ・特売情報・Notion・Gemini AIをまとめて扱う個人向けBotです。

## ドキュメント

- `SETUP.md`: 初期構築、環境変数、Notion DB、GAS、Render設定
- `MAINTENANCE.md`: 日常保守、障害切り分け、復旧
- `DEVELOPMENT.md`: 長期ロードマップ、進捗、次回再開位置
- `UI_DESIGN.md`: LINE UIとPostback設計ルール
- `PHASE1_TEST.md`: カード自動化テスト
- `PHASE2_TEST.md`: 月次・予算判断テスト
- `PHASE3_TEST.md`: Phase 3A/3B テスト
- `FLYER_TEST.md`: サミットチラシ・生活カレンダー実機テスト
- `gas/README.md`: GAS固有設定

機能変更時は README.md / SETUP.md / DEVELOPMENT.md を更新し、UI変更時は UI_DESIGN.md も更新します。

# 今日の特売をLINEコマンドで表示

状態: **実装済み・要実機確認**

サミット ミナノ分倍河原店の特売DBから、今日有効・確認済みの特売をLINEで呼び出せます。

```text
特売
特売情報
今日の特売
本日の特売
サミット特売
```

短期特売を先に表示し、月間・長期特売を後に表示します。最大20件です。メインメニューにも `🛒 特売・買い物 → 今日の特売を見る` を追加しています。

Renderでは実運用中の特売DBを明示的に設定します。

```text
NOTION_FLYER_DATABASE_ID=3d90efb323d080b5999bed1820a6665e
```

`flyer_command.py` は誤ったDBを読まないよう、現在は未設定時のハードコードフォールバックを使いません。日次の自動特売通知はこれまで通りGAS側で動作します。

# Phase 3A — 自然文家計簿入力・支出テンプレート

状態: **実装済み・要実機確認**

普通の文章から支出を読み取れます。

```text
今日サミットで2380円使った
昨日コンビニで540円買った
9月10日にスタバで680円払った
```

金額・店名・日付を読み取り、ジャンルや支払方法が文中にない場合はLINEのボタンで確認します。最終確認の「この内容で登録」を押すまでNotionへ保存しません。

使い方確認:

```text
自然文入力
```

よく使う支出:

```text
支出テンプレート
```

直近90日の家計簿から、よく使う `店名 + ジャンル + 支払方法` を自動で候補化し、金額はその組み合わせの中央値を表示します。テンプレートも確認後に登録します。専用DBは不要です。

# ジャンル別予算

`予算 お菓子 3000` のようなジャンル予算に対応しています。

```text
予算 100000
予算 お菓子 3000
予算 2026-10 食費 35000
```

月別管理DBに `お菓子予算` のようなNumberプロパティがまだ存在しない場合は、Botがその列を自動追加してから保存します。

# Phase 3B — 直前登録の修正・取り消し

状態: **実装済み・要実機確認**

```text
直前登録
直前修正
直前取り消し
```

`直前登録` で家計簿DBの最新1件を表示し、金額 / 店名 / 日付 / ジャンル / 支払方法を修正できます。

```text
直前修正 金額 1500
直前修正 店名 サミット
直前修正 日付 2026-09-12
直前修正 ジャンル 食費
直前修正 支払方法 JCB
```

`直前取り消し` は確認後にNotionページをアーカイブします。
