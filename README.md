# LINE Notion Bot

LINEを入口に、家計簿・予算・カード利用通知・固定費/サブスク・貸し借り・メモ・Notion・Gemini AIをまとめて扱う個人向けBotです。

## ドキュメント

- `SETUP.md`: 初期構築、環境変数、Notion DB、GAS、Render設定
- `MAINTENANCE.md`: 日常保守、障害切り分け、復旧
- `DEVELOPMENT.md`: 長期ロードマップ、進捗、次回再開位置
- `UI_DESIGN.md`: LINE UIとPostback設計ルール
- `PHASE1_TEST.md`: カード自動化テスト
- `PHASE2_TEST.md`: 月次・予算判断テスト
- `PHASE3_TEST.md`: Phase 3B 修正・取り消しテスト
- `FLYER_TEST.md`: サミットチラシ・生活カレンダー実機テスト
- `gas/README.md`: GAS固有設定

機能変更時は README.md / SETUP.md / DEVELOPMENT.md を更新し、UI変更時は UI_DESIGN.md も更新します。

# 「この機能ある？」案内

状態: **実装済み・要実機確認**

```text
機能確認 貸し借り
機能確認 旅行のためにお金を貯める
貸し借りの記録ってできる？
```

判定順:

```text
1. 登録済み機能名・別名で確認
2. 見つからなければGeminiが既存機能一覧から推定
3. 既存機能で可能 → 使い方を回答
4. ロードマップ済み → 未実装と予定を回答
5. Geminiも「ない」と判断 → 入力された機能名を機能追加要望DBへ登録
```

Gemini障害時は誤って要望DBへ登録しません。

Render環境変数:

```text
NOTION_FEATURE_REQUEST_DATABASE_ID=76e4fe5d248e4fd1a48f45e9bdd59e8c
```

# Phase 3B — 直前登録の修正・取り消し

状態: **実装済み・要実機確認**

```text
直前登録
直前修正
直前取り消し
```

`直前登録` で家計簿DBの最新1件を表示し、次を修正できます。

```text
金額
店名
日付
ジャンル
支払方法
```

例:

```text
直前修正 金額 1500
直前修正 店名 サミット
直前修正 日付 2026-09-12
直前修正 ジャンル 食費
直前修正 支払方法 JCB
```

`直前取り消し` は対象を表示して確認後、Notionページをアーカイブします。いきなり消しません。

# ボタンを押したことがすぐ分かるUI

LINEの `message` action は押した瞬間に選択内容がトークへ表示されます。Postbackが必要なボタンには `displayText` を追加しました。

現在、主に以下へ反映しています。

```text
メニュー内のPostback
ジャンル選択
支払方法選択
カード分類・まとめ処理・店名変更
重複確認
自動登録ON/OFF
毎月1日の予算設定
```

そのためRender側の応答に数秒かかっても、先に「▶ 食費」「▶ 店名を変更する」などが表示され、タップ済みか確認できます。
