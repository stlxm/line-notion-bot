# LINE Notion Bot

LINEを入口に、家計簿・予算・カード利用通知・固定費/サブスク・貸し借り・メモ・特売情報・Notion・Gemini AIをまとめて扱う個人向けBotです。

## ドキュメント

- `SETUP.md`: 初期構築、環境変数、Notion DB、GAS、Render設定
- `MAINTENANCE.md`: 日常保守、障害切り分け、復旧
- `DEVELOPMENT.md`: 長期ロードマップ、進捗、次回再開位置
- `UI_DESIGN.md`: LINE UIとPostback設計ルール
- `PHASE1_TEST.md`: カード自動化テスト
- `PHASE2_TEST.md`: 月次・予算判断テスト
- `PHASE3_TEST.md`: Phase 3A/3B テスト
- `FLYER_TEST.md`: サミットチラシ・生活カレンダー実機テスト
- `gas/README.md`: GAS固有設定

機能変更時は README.md / SETUP.md / DEVELOPMENT.md を更新し、UI変更時は UI_DESIGN.md も更新します。

# Phase 4 — メモ・URLを行動に変える

状態: **実装済み・要実機確認**

正式対象:

```text
#50 メモ期限
#53 メモ自動分類
#54 買い物リスト
#56 URL保存時タイトル取得
#57 URLカテゴリ分類
```

期限付きメモ:

```text
メモ 住民票を明日までに提出
メモ 9/20までに大学へ連絡
```

`今日 / 明日 / 明後日 / YYYY-MM-DD / M/D` を期限として読み取り、メモDBの `期限` に保存します。分類はルールベースで `買い物 / やること / 予定 / アイデア / その他` に自動分類します。

買い物リスト:

```text
買い物 牛乳
買い物 洗濯ネット
買い物リスト
買った 牛乳
```

既存メモDBを使い、`分類=買い物` と `完了` を管理します。同じキーワードに複数一致した場合は勝手に完了せず、詳しい指定を求めます。

URL保存:

```text
https://example.com/...
```

URLをそのままLINEへ送ると、ページの `<title>`、ドメイン、カテゴリを取得して `後で見るURL` DBへ保存します。カテゴリは `記事 / 買い物 / 動画 / SNS / 資料 / その他` です。Geminiは使いません。

NotionスキーマもPhase 4用に拡張済みです。

```text
メモDB: 期限 / 分類 / 完了
後で見るURL DB: ページタイトル / カテゴリ / ドメイン / 保存日時
```

# 今日の特売をLINEコマンドで表示

状態: **実機確認済み**

サミット ミナノ分倍河原店の生活カレンダーから、今日有効・確認済みの特売をLINEで呼び出せます。

```text
特売
特売情報
今日の特売
本日の特売
サミット特売
```

短期特売を先に表示し、月間・長期特売を後に表示します。最大20件です。メインメニューにも `🛒 特売・買い物 → 今日の特売を見る` を追加しています。

実運用中の取得元は `生活カレンダー` DBです。

```text
NOTION_FLYER_DATABASE_ID=684f959e451047389505a95ed368a7d6
```

`3d90efb323d080b5999bed1820a6665e` は削除済みの旧 `特売カレンダー` なので使用しません。
